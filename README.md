
Google

Yo creo que Google puede utilizar una tabla hash
porque necesita buscar y relacionar mucha información de una manera rápida 
Por ejemplo, cuando escribimos una palabra en el buscador 
puede utilizar palabras clave para encontrar rápidamente páginas
y resultados relacionados con lo que estamos buscando.

Instagram

Pienso que Instagram puede utilizar listas enlazadas en algunas partes de su funcionamiento, 
por ejemplo, para manejar elementos que están relacionados entre sí, como publicaciones o contenido que se va cargando. 
Cada elemento puede estar conectado con otro y así se puede recorrer la información de una publicación a la siguiente.

TikTok

Creo que TikTok puede utilizar una tabla hash para organizar información relacionada con los usuarios 
y sus interacciones. 
Por ejemplo, puede relacionar rápidamente a un usuario con los videos que ha visto, los que le han gustado o con los temas que más busca, para después mostrarle contenido parecido
¿Cuál me pareció más difícil?

La estructura que más me costó entender fue la lista enlazada
porque al principio no comprendía muy bien cómo funcionaban los nodos y las conexiones entre ellos
Después de practicar con ejemplos entendí que cada nodo guarda un dato y una referencia que indica cuál es el siguiente.
